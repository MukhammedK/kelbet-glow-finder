# Hero по новому референсу

- Перестроить только композицию существующего Hero по прикреплённому примеру: текст слева, девушка справа, косметика крупно на переднем плане и сакура вокруг.
- Убрать визуальное ощущение отдельной прямоугольной фотографии, сохранив мягкое смешивание с розовым фоном.
- Сохранить без изменений все тексты, кнопку, рукописную подпись, прокрутку и нижнюю волну.
- Проверить мобильный и большой экран: лицо, апельсины и косметика видны, текст не перекрыт, горизонтальной прокрутки нет.
