# KELBET Beauty Journey

Создай полностью готовый mobile-first одностраничный сайт для бренда KELBET — магазина люксовой косметики и ухода из Южной Кореи.

ВАЖНО:

Я прикрепил визуальные примеры блоков, которые мы разработали отдельно. Используй их как главный визуальный референс. Сохрани общую стилистику, цветовую палитру, типографику, композицию, настроение и плавные переходы между блоками.

Это НЕ обычный интернет-магазин.

На сайте НЕ должно быть:

- корзины

- поиска

- каталога с добавлением товаров

- меню с множеством разделов

- авторизации

- онлайн-оплаты

Главная цель сайта:

Пользователь приходит с TikTok → знакомится с KELBET → понимает ассортимент → проходит интерактивный подбор ухода → получает персональный результат → нажимает кнопку и переходит в WhatsApp с автоматически сформированным сообщением на основе своих ответов.
